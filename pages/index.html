DeckPilot plugin registry

No signed registry is published yet. The registry is being set up. There are no production signing keys and no published plugins, so /v1/ holds no registry documents and DeckPilot reports the registry as unavailable.

What this is

The community plugin registry of DeckPilot, served as static files. DeckPilot trusts these files only through signatures it checks itself: a root-signed key set, an index signed by the index key, and a timestamp re-signed at least weekly. Packages are downloaded from the repository's GitHub Releases and must match the sha256 and size the signed index pins.

Contributing a plugin

Plugins are submitted by pull request to knittingcode/deckpilot-plugins; see CONTRIBUTING.md. To report a malicious plugin or a registry vulnerability, see SECURITY.md.

DeckPilot is open source under the Apache-2.0 license. Each plugin carries its own license.
